# Sparse PHATE — Reproducible Pipeline

Every command is copy-paste runnable from `Python/`. All output is generated, nothing pre-baked.

## Quick start — one command

```bash
uv run python scripts/dense_vs_sparse.py
# → plots/dense_vs_sparse.png
```

That script generates tree data, runs dense and sparse PHATE at t=1,2,4,8, and saves the comparison plot. No input files needed.

## Step by step

### 1. Generate tree data → parquet

```bash
uv run python -c "
from phate.tree import gen_dla
import pandas as pd

data, clusters = gen_dla(n_dim=512, n_branch=100, branch_length=500, seed=42)
df = pd.DataFrame(data.astype('float32'))
df.insert(0, 'branch', clusters.astype('int32'))
df.to_parquet('tree_50k.parquet', index=False)
print(f'Saved: {data.shape} → tree_50k.parquet')
"
```

### 2. Run sparse PHATE via CLI

```bash
uv run python cli.py -c pipeline_50k.yml
```

This reads `tree_50k.parquet`, runs sparse PHATE with k=100, t=2, and writes `embedding_50k.parquet` + `plots/phate_embedding.png`.

### 3. Try different parameters

```bash
# Override any YAML field from the command line
uv run python cli.py -c pipeline_50k.yml -t 8 --sparse-k 50
uv run python cli.py -c pipeline_50k.yml --device cuda --batch-size 1024
```

### 4. Grid search: t=1..10 × k=[10, 50, 100]

```bash
uv run python scripts/t_k_grid.py
# → plots/t_k_grid.png  (3×10 panel, ~5 minutes)
```

Reads `tree_50k.parquet` (generated in step 1).

### 5. Scale benchmark

```bash
uv run python scale_bench.py
```

Runs N=10K, 20K, 50K, 100K, 200K — prints per-step timings. No input files, generates random data on the fly.

## YAML reference (`pipeline_50k.yml`)

```yaml
input: tree_50k.parquet       # .parquet, .csv, .tsv, .npy, .h5ad
output: embedding_50k.parquet # output columns: x_0..x_{d-1}
sparse_k: 100                 # top-k neighbors (50–100 for tree data)
t: 2                          # diffusion steps (1=local, 8=global)
gamma: 1.0                    # potential transform: 1=log, 0=sqrt
decay: 40.0                   # kernel bandwidth
sparse_metric: euclidean      # euclidean | cosine | correlation
n_components: 2               # embedding dimensions
batch_size: 256               # rows per batch (1024 for GPU)
sparse_device: cpu            # cpu | cuda | mps
plot_dir: plots               # output directory (or null to skip)
plot_format: png              # png (matplotlib) | html (plotly)
verbose: true
```
