# Sparse PHATE — Reproducible Pipeline

All commands run from this directory. Nothing pre-baked — every file is either generated by a command or committed. Figures are embedded below.

## Quick start (no input files needed)

```bash
uv run python ./scripts/dense_vs_sparse.py
```

![dense vs sparse](plots/dense_vs_sparse.png)

## Step by step

### 1. Generate tree data → parquet

```bash
uv run python -c "
from phate.tree import gen_dla
import pandas as pd

data, clusters = gen_dla(n_dim=512, n_branch=100, branch_length=500, seed=42)
df = pd.DataFrame(data.astype('float32'))
df.insert(0, 'branch', clusters.astype('int32'))
df.to_parquet('./tree_50k.parquet', index=False)
print(f'Saved: {data.shape} -> ./tree_50k.parquet')
"
```

### 2. Run sparse PHATE via CLI

```bash
uv run python ./cli.py -c ./pipeline_50k.yml
```

Reads `./tree_50k.parquet`, writes `./embedding_50k.parquet` + plot:

![phate embedding](plots/phate_embedding.png)

### 3. Try different parameters

```bash
uv run python ./cli.py -c ./pipeline_50k.yml -t 8 --sparse-k 100
uv run python ./cli.py -c ./pipeline_50k.yml --device cuda --batch-size 1024
```

## `pipeline_50k.yml` reference

```yaml
input: ./tree_50k.parquet        # .parquet, .csv, .tsv, .npy, .h5ad
output: ./embedding_50k.parquet  # columns: x_0 .. x_{ndim-1}
sparse_k: 50                     # top-k neighbors
t: 2                             # diffusion steps (1=local, 8=global)
gamma: 1.0                       # potential: 1=log, 0=sqrt
decay: 40.0                      # kernel bandwidth
sparse_metric: euclidean         # euclidean | cosine | correlation
n_components: 2                  # embedding dims
batch_size: 256                  # rows per batch (1024 for GPU)
sparse_device: cpu               # cpu | cuda | mps
plot_dir: ./plots                # output dir (null to skip)
plot_format: png                 # png (matplotlib) | html (plotly)
verbose: true
```
